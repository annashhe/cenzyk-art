# cenzyk.art — рендеры для КП

Рабочая ветка для визуализаций ковки под коммерческие предложения заказчикам.

## Правила сцен

- **Матрас всегда** `1800 × 2000 × 210 мм`, размеры подписать на матрасе
- Матрас **не красить**
- Металл — текстура **Antique Gold** (см. `docs/RENDER-BRIEF.md`)

## Файлы

| Путь | Назначение |
|------|------------|
| `docs/RENDER-BRIEF.md` | Бриф текстуры и вариантов |
| `renders/beds/bed-v1-antique-gold.png` | Рендер кровати, вариант 1 |
| `renders/kp/bed-v1.html` | Упаковка кадра в лист КП |

## Просмотр

```bash
python3 -m http.server 4173
```

Открыть: http://127.0.0.1:4173/renders/kp/bed-v1.html
