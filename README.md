# Производственная калькуляция

Шаблон внутренней оценки рентабельности проекта и расчёта цены КП для самозанятого производства металлоконструкций (ворота, заборы, лестницы, мебель, интерьер).

## Файл

- `templates/Калькуляция_проект_v1.xlsx` — рабочий шаблон
- `scripts/build_kalkulyaciya.py` — пересборка шаблона
- `docs/kalkulyaciya-model.md` — описание модели

## Быстрый старт

1. Откройте `templates/Калькуляция_проект_v1.xlsx`
2. Проверьте лист **Параметры**
3. Заполните **Металл** и количества в **Калькуляция**
4. На **Сводке** возьмите рекомендуемую цену и впишите цену КП

Пересборка:

```bash
python3 scripts/build_kalkulyaciya.py
```
