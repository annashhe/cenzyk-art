# Модель калькуляции проекта

Шаблон: `templates/Калькуляция_проект_v1.xlsx` (копия ASCII: `templates/Kalkulyaciya_proekt_v1.xlsx`)  
Сборка: `python3 scripts/build_kalkulyaciya.py`

## Главный контур
Металл → Калькуляция → Сводка (цена КП)

## Касса
Опциональный лист после сделки. На цену и маржу не влияет. Из Сводки только читает цену КП.

## Металл
Прокат: 31 позиция, цена за шт = штанга 6 м. Плазма/лазер, ковка, токарка — по 10 строк.
