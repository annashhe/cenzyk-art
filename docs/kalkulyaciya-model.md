# Модель калькуляции проекта

Шаблон: `templates/Калькуляция_проект_v1.xlsx`  
Сборка: `python3 scripts/build_kalkulyaciya.py`

## Назначение

Внутренняя оценка рентабельности до выставления коммерческого предложения (самозанятость, металлоконструкции / ковка / монтаж).

## Листы

| Лист | Роль |
|------|------|
| Сводка | P&L, рекомендуемая цена, статус маржи, таблица 10%…35% |
| Калькуляция | Этапы заказа, типы затрат, связь с Металлом |
| Металл | Прокат / плазма / ковка / токарка |
| Параметры | % менеджера, целевая/мин. маржа, НПД, аренда/день |
| Касса заказа | Факт денег (не прибыль) |
| Инструкция | Краткий порядок работы |

## Формулы

- Себестоимость строки: `цена × кол-во`
- Наценка менеджера (только тип `закупка`): `себестоимость × %`
- Цена при целевой марже: `P = C / (1 − НПД% − маржа% − агентские%)`
- Прибыль: `P − C − НПД − агентские`
- Маржа %: `прибыль / P`

## Жёлтые ячейки

Только ввод. Серые/голубые — расчётные, не перетирать.
