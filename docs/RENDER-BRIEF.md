# Бриф рендеров для КП — cenzyk.art

## Золотая текстура (каркас / ковка)

Источник: фото интерьера (бра + изголовье кровати).

| Параметр | Значение |
|----------|----------|
| Название | Antique Gold / Aged Brass |
| База | Приглушённый тёплый бледно-золотой |
| Блики | Соломенно-жёлтый на выступах |
| Патина | Тёмно-коричневая / чёрная в углублениях |
| Шелковистость | Сатин / мат, без зеркала |
| Поверхность | Зернистая, лёгкий brushed, слегка пористая |

Красим только металл (каркас, ковка, фурнитура).

## Матрас (во всех сценах)

- Размер: **1800 × 2000 × 210 мм**
- На матрасе **обязательно** указать размеры текстом
- **Не красить** — нейтральный белый / светло-серый текстиль
